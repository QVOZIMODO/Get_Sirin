# Быстрый старт

От нуля до работающего соединения — за пару минут. Без регистрации, без email, без карты.

{% hint style="info" %}
**Перед началом**

* Telegram (последняя версия)
* Способ оплаты: **Telegram Stars** для 7-дневного пробного доступа или **криптокошелёк** с небольшим балансом для Ежемесячного / Годового тарифа
* VPN-клиент для вашего устройства — его вы выберете на шаге [Установка](../ustanovka/) (большинство начинает с AmneziaVPN)
{% endhint %}

## Пять шагов

{% stepper %}
{% step %}
### Откройте бота

Перейдите в [@getsirin\_bot](https://t.me/getsirin_bot) или отсканируйте QR-код на [sirin.one](https://sirin.one), затем нажмите **Start**.

<figure><img src=".gitbook/assets/qs-bot-start.png" alt="Профиль бота Sirin с кнопкой Start"><figcaption>[REAL CAPTURE] Экран профиля @getsirin_bot с кнопкой Start</figcaption></figure>
{% endstep %}

{% step %}
### Выберите язык

При первом запуске бот предлагает **русский или английский** в виде кнопок. Сменить язык можно в любой момент через кнопку **🌐** в меню — отдельной команды для этого нет.
{% endstep %}

{% step %}
### Выберите план

| План | Цена | Оплата |
| --- | --- | --- |
| **Пробный** | 99 ⭐ (≈ $1.99) · 7 дней | Telegram Stars |
| **Ежемесячный** | $7 / мес | Крипта |
| **Годовой** | $60 / год | Крипта |

Полный разбор — в разделе [Выбор плана](vybor-plana.md).

<figure><img src=".gitbook/assets/qs-plan-menu.png" alt="Меню выбора плана в боте"><figcaption>[REAL CAPTURE] Меню выбора плана в @getsirin_bot</figcaption></figure>

{% hint style="info" %}
**Stars оплачивают только пробный доступ.** Ежемесячный и Годовой оплачиваются криптой — см. [Оплата криптой](oplata-kriptoi.md).
{% endhint %}
{% endstep %}

{% step %}
### Оплатите

{% tabs %}
{% tab title="Пробный — Telegram Stars" %}
Нажмите, чтобы оплатить **99 ⭐** через встроенную оплату Telegram. Одно нажатие, без блокчейна, мгновенно.
{% endtab %}

{% tab title="Ежемесячный / Годовой — Крипта" %}
Выберите монету — **USDT (TRC-20)**, **TON**, **BTC** или **XMR** (нажмите **Другие монеты →** для остальных) — и переведите точную сумму на адрес, который покажет бот. Подтверждение обычно приходит за несколько минут.
{% endtab %}
{% endtabs %}

<figure><img src=".gitbook/assets/qs-payment.png" alt="Экран оплаты криптой с адресом и QR-кодом"><figcaption>[REAL CAPTURE] Экран оплаты криптой с адресом и QR-кодом</figcaption></figure>
{% endstep %}

{% step %}
### Получите конфигурацию и подключитесь

После подтверждения платежа бот пришлёт вам персональную ссылку на подписку (`https://sub.sirin.one/…`) и QR-код. **Одна ссылка — все четыре протокола, обе стороны.**

Откройте клиент, импортируйте подписку через QR-код или ссылку и включите соединение.

<figure><img src=".gitbook/assets/qs-delivery.png" alt="Сообщение бота со ссылкой на подписку и QR-кодом"><figcaption>[REAL CAPTURE] Сообщение бота со ссылкой на подписку и QR-кодом</figcaption></figure>
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Готово. Никакого аккаунта, ничего не нужно помнить, кроме бота.
{% endhint %}

## Что вы на самом деле получили

* **Все четыре протокола** в одной подписке — WireGuard, AmneziaWG, VLESS + Reality, Shadowsocks
* **Серверы в обе стороны** — за пределами России и внутри неё
* **Без логов активности и трафика** — только метрики здоровья эндпоинтов

{% hint style="info" %}
🔭 **В планах — автоматическая ротация.** Сейчас вы переключаете протоколы и серверы в один тап, а ваш клиент при каждом обновлении подхватывает свежий список серверов, ранжированный по их состоянию. Полностью автоматическая ротация «переключит раньше, чем вы заметите» появится с отдельным приложением Sirin, уже после запуска.
{% endhint %}

## Если что-то не работает

* **QR не сканируется** — скопируйте ссылку из Telegram и вставьте её в клиент вручную.
* **Один протокол не подключается** — переключитесь на другой; ради этого их и четыре.
* **Всё ещё не получается** — см. [Устранение неполадок](../podderzhka/ustranenie-nepoladok.md) или отправьте `/support` в боте.
