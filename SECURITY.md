# Security disclosure

Found a vulnerability in Sirin? We want to hear about it, and we'll act on it.

- **Coordinated disclosure:** see **[sirin.one/security](https://sirin.one/security)** for
  the current disclosure process and contact, mirrored in our published
  [`security.txt`](https://sirin.one/.well-known/security.txt).
- **Reach us:** through the bot, **[@getsirin_bot](https://t.me/getsirin_bot)**.

Please give us a reasonable window to remediate before any public disclosure. We don't run a
paid bounty at this stage, but we credit researchers who report in good faith (and want to
be credited).

> Note: this repository is a public *overview*. It contains no operational source code, so
> findings here would relate to the documentation or brand assets. Service-level issues
> should go through the disclosure channel above.
